### Security Guidelines

#### **Password Policy**
- Never share credentials outside authorized team
- Use two-factor authentication where available
- Change passwords every 90 days for critical accounts
- Report any suspected security breaches immediately
- Store credentials securely using approved password managers

#### **Access Management**
- Credentials are role-based and need-to-know
- Revoke access immediately upon team changes
- Regular audit of active accounts and permissions
- Monitor account activity for suspicious behavior
