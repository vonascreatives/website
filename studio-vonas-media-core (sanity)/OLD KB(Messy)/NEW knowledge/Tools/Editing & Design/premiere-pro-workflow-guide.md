# Premiere Pro Workflow Guide

## Description
Standardized Adobe Premiere Pro workflow for VONAS Media video production including project setup, editing protocols, export settings, and quality control procedures to ensure consistent professional output.

## Steps
1. Set up project with standard VONAS Media settings
2. Organize media files and create efficient workflow
3. Execute editing following brand guidelines
4. Apply color correction and audio enhancement
5. Export using standardized settings and quality check

### Editing Workflow Protocol

#### Phase 1: Assembly Edit (Day 1)
1. **Media Import and Organization**
   - Import all footage using standardized naming
   - Create bins for different camera angles
   - Sync audio if recorded separately
   - Create proxy media for smooth playback

2. **Rough Cut Assembly**  
   - Lay down primary camera angle
   - Mark key conversation points
   - Remove obvious technical issues
   - Create basic story structure

#### Phase 2: Fine Cut (Day 2-3)
1. **Multi-Camera Editing**
   - Switch between angles based on speaker
   - Maintain visual interest with appropriate cuts
   - Remove excessive "ums," long pauses, and filler

2. **Story and Flow Refinement**
   - Ensure logical conversation flow
   - Maintain authentic feel while improving pace
   - Add cutaways and B-roll where available

#### Phase 3: Finishing (Day 4-5)
1. **Graphics and Branding**
   - Apply standard VONAS Media intro/outro
   - Add lower thirds with consistent style
   - Include show-specific graphics and branding

2. **Color Correction and Grading**
   - Apply basic exposure and color correction
   - Ensure consistent look across all camera angles
   - Apply subtle creative grading to match show style

3. **Audio Post-Production**
   - Normalize audio levels (-23 LUFS for broadcast)
   - Apply noise reduction if needed
   - Add subtle background music where appropriate
   - Ensure clear, professional audio quality

### Export Settings

#### Full Episode Export
- **Format**: H.264, High Quality
- **Resolution**: 1920x1080
- **Frame Rate**: Match source (24fps/30fps)  
- **Bitrate**: VBR, 2 pass, 8-12 Mbps
- **Audio**: AAC, 320 kbps, 48kHz

#### Social Media Cuts
- **Instagram/TikTok**: 9:16, 1080x1920
- **YouTube Shorts**: 9:16, 1080x1920  
- **Facebook**: 16:9, 1920x1080
- **Twitter**: 16:9, 1280x720

#### Archive/Master Copy
- **Format**: ProRes 422 HQ
- **Resolution**: Source resolution
- **Frame Rate**: Source frame rate
- **Purpose**: High-quality master for future use

### Quality Control Checklist

#### Technical Review
- [ ] Audio sync throughout entire video
- [ ] No visible technical glitches or artifacts
- [ ] Consistent color and exposure
- [ ] Audio levels within broadcast standards
- [ ] All graphics and text properly positioned

#### Content Review
- [ ] Story flows logically and engagingly
- [ ] Brand elements correctly applied
- [ ] Guest information accurate in lower thirds
- [ ] No content that violates guidelines
- [ ] Proper show format maintained

#### Final Delivery
- [ ] Multiple format exports completed
- [ ] File naming follows standard convention
- [ ] Files uploaded to designated locations
- [ ] Project archived with all assets
- [ ] Export log documented for reference
