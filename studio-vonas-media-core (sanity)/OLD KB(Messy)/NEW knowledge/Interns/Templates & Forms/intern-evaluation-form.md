# Intern Evaluation Form Template

## Description
Standardized evaluation template for assessing intern performance at 30, 60, and 90-day intervals, providing structured feedback and development planning.

## Steps
1. Schedule evaluation meeting with intern and mentor
2. Complete evaluation form with specific examples and ratings
3. Discuss results with intern in structured feedback session
4. Develop action plan for improvement or advancement
5. Document outcomes and schedule next evaluation
