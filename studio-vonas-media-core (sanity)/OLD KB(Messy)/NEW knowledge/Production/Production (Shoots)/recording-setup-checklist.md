# Recording Setup Checklist

## Description
Comprehensive pre-recording setup checklist ensuring professional-quality recordings with proper equipment configuration, audio/video settings, and backup procedures.

## Steps
1. Confirm recording schedule and guest/host availability
2. Set up and test all audio and video equipment
3. Configure recording software and backup systems
4. Conduct final technical checks and guest tech test
5. Execute recording with monitoring and quality control

## Content

### Pre-Recording Preparation (24-48 Hours Before)

#### Schedule Confirmation
- [ ] **Recording Date and Time**: Confirmed with all participants
- [ ] **Time Zone Verification**: Especially for remote guests
- [ ] **Duration Estimate**: Expected recording length communicated
- [ ] **Guest Tech Test**: Scheduled 15-30 minutes before recording
- [ ] **Backup Date**: Alternative date identified in case of issues

#### Location and Setup Planning
- [ ] **Recording Location**: Confirmed and prepared (studio/remote)
- [ ] **Room Acoustics**: Sound treatment checked and optimized
- [ ] **Lighting Setup**: Natural/artificial lighting planned
- [ ] **Background/Set**: Visual elements arranged and cleaned
- [ ] **Power and Connectivity**: Outlets and internet confirmed

### Equipment Setup and Configuration

#### Camera Setup
- [ ] **Primary Camera**: Positioned and framed for main shots
- [ ] **Secondary Camera(s)**: Angle shots and guest coverage
- [ ] **Camera Settings**: Resolution (4K/1080p), frame rate (24/30fps)
- [ ] **Focus and Exposure**: Manual settings locked in
- [ ] **White Balance**: Adjusted for lighting conditions
- [ ] **Memory Cards**: Formatted with sufficient storage space
- [ ] **Battery Levels**: Fully charged with backup batteries ready

#### Audio Equipment Configuration
- [ ] **Microphones**: Lavalier/shotgun/dynamic mics positioned
- [ ] **Audio Interface**: Connected and receiving clean signals
- [ ] **Headphone Monitoring**: Available for real-time audio check
- [ ] **Audio Levels**: Proper gain staging (-12dB to -6dB)
- [ ] **Room Tone Recording**: 30 seconds of ambient sound captured
- [ ] **Backup Audio**: Secondary recording device configured
- [ ] **Wind/Pop Protection**: Windscreens and pop filters in place

#### Lighting Setup
- [ ] **Key Light**: Primary subject illumination positioned
- [ ] **Fill Light**: Shadow reduction light configured
- [ ] **Background Light**: Separation and depth lighting set
- [ ] **Color Temperature**: Consistent lighting temperature (5600K/3200K)
- [ ] **Light Modifiers**: Softboxes/diffusers positioned as needed
- [ ] **Practical Lights**: Any visible lights in shot addressed

### Recording Software and Systems

#### Primary Recording Setup
- [ ] **Recording Software**: Launched and configured (OBS/Premiere/etc.)
- [ ] **Project Settings**: Correct resolution, frame rate, audio settings
- [ ] **File Locations**: Recording destination with sufficient storage
- [ ] **Codec Settings**: High-quality settings for archival recording
- [ ] **Multi-Track Audio**: Separate tracks for each microphone
- [ ] **Video Sources**: All cameras feeding into recording system

#### Backup Recording Systems
- [ ] **Secondary Recording**: Independent backup recording running
- [ ] **Cloud Backup**: Real-time or post-recording cloud sync
- [ ] **Local Backup**: Multiple local drives for redundancy
- [ ] **Memory Card Backups**: In-camera recording as additional backup
- [ ] **Audio Backup**: Separate audio recorder running independently

### Technical Testing Phase

#### Video Quality Check
- [ ] **Image Quality**: Sharp focus, proper exposure, good color
- [ ] **Frame Rate**: Smooth motion, no dropped frames
- [ ] **Composition**: All subjects properly framed
- [ ] **Stability**: Cameras stable, no unwanted movement
- [ ] **Recording Indicator**: Confirm all cameras recording
- [ ] **Storage Monitoring**: Sufficient space for full recording

#### Audio Quality Verification
- [ ] **Signal Strength**: Strong, clean audio signals
- [ ] **No Interference**: Free from electrical hum or RF interference
- [ ] **Sync Test**: Audio and video synchronization confirmed
- [ ] **Background Noise**: Minimal ambient noise levels
- [ ] **Voice Clarity**: Clear intelligible speech
- [ ] **Backup Audio Sync**: Secondary recordings in sync

### Guest Technical Check (15 Minutes Before)

#### For In-Person Guests
- [ ] **Microphone Check**: Guest mic levels and positioning
- [ ] **Comfort Assessment**: Seating and environment comfortable
- [ ] **Visual Check**: Appearance and framing satisfactory
- [ ] **Coaching**: Brief instruction on microphone technique
- [ ] **Questions**: Address any technical concerns

#### For Remote Guests
- [ ] **Connection Test**: Stable internet and software connection
- [ ] **Audio Quality**: Guest microphone and audio settings
- [ ] **Video Quality**: Camera, lighting, and background check
- [ ] **Screen Share**: Test if presentation materials needed
- [ ] **Backup Communication**: Phone number for emergency contact
- [ ] **Recording Consent**: Confirm permission to record

### Final Pre-Recording Checklist

#### System Status Verification
- [ ] **All Equipment Recording**: Every device showing recording status
- [ ] **Storage Space**: Adequate space for full session
- [ ] **Battery Levels**: All devices sufficiently charged
- [ ] **Network Stability**: Strong, stable internet connection
- [ ] **Backup Systems**: All redundancy systems operational
- [ ] **Emergency Contacts**: Technical support numbers available

#### Team Coordination
- [ ] **Role Assignments**: Everyone knows their responsibilities
- [ ] **Communication**: Silent communication methods established
- [ ] **Monitoring**: Someone assigned to technical monitoring
- [ ] **Time Management**: Start time confirmed with all parties
- [ ] **Contingency Plans**: Backup plans for common issues

### During Recording Monitoring

#### Continuous Monitoring Tasks
- [ ] **Audio Levels**: Consistent monitoring for clipping or low levels
- [ ] **Video Quality**: Regular check for focus, exposure, framing
- [ ] **Recording Status**: Confirm all systems continue recording
- [ ] **Storage Space**: Monitor available storage throughout
- [ ] **Connection Stability**: Watch for network issues (remote)
- [ ] **Guest Comfort**: Periodic comfort checks during breaks

#### Issue Response Protocols
- [ ] **Audio Problems**: Quick troubleshooting steps prepared
- [ ] **Video Issues**: Camera adjustment procedures ready
- [ ] **Technical Failures**: Backup activation procedures
- [ ] **Network Issues**: Alternative connection methods
- [ ] **Guest Issues**: Support and problem-solving approaches

### Post-Recording Immediate Tasks

#### File Management
- [ ] **Stop All Recordings**: Properly end all recording systems
- [ ] **File Verification**: Confirm all files recorded successfully
- [ ] **Backup Creation**: Immediate backup of all files
- [ ] **File Organization**: Proper naming and folder organization
- [ ] **Quality Check**: Quick review of recorded material
- [ ] **Metadata Addition**: Add relevant information to files

#### Equipment Shutdown
- [ ] **Proper Shutdown**: Safely power down all equipment
- [ ] **Media Removal**: Secure removal of memory cards/drives
- [ ] **Equipment Storage**: Return equipment to proper storage
- [ ] **Cable Management**: Organize and store cables properly
- [ ] **Cleaning**: Clean equipment as needed
- [ ] **Inventory Check**: Ensure all equipment accounted for

## Checklist Summary

- [ ] All equipment set up and configured properly
- [ ] Recording software and backup systems operational
- [ ] Technical testing phase passed all quality checks
- [ ] Guest technical check completed successfully
- [ ] Final pre-recording verification completed
- [ ] Monitoring protocols established and executed
- [ ] Post-recording file management completed
- [ ] Equipment properly shut down and stored
- [ ] Quality assurance check performed on recordings
