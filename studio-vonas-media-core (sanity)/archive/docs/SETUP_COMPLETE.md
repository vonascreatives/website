## 🚀 How to Use

### Access Your Studio
1. **Deployed Version**: Visit https://vonas-media.sanity.studio/
2. **Local Development**: Run `npm run dev` and visit http://localhost:3333/

### Test File Uploads
- Go to the "Media Asset" section
- Click "Create new"
- Upload actual images, videos, or documents
- Add titles, descriptions, and tags

### MCP Server (AI Integration)
- Configured but requires API token setup
- See README.md for full instructions

## 🛠 Available Commands

```bash
npm run dev          # Start local development server
npm run deploy       # Deploy studio to sanity.studio
npm run import-data  # Import more dummy content
npm run add-media    # Add sample media assets
npm run mcp-server   # Start MCP server for AI integration
```
