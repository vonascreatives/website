## ⚡ FASTEST WAY TO ADD IMAGES:

### Step 1: Open multiple tabs
- Tab 1: https://unsplash.com/
- Tab 2: Your Sanity Studio (http://localhost:3333/)

### Step 2: For each document:
1. Search for relevant image on Unsplash
2. Download the image (1200px wide recommended)
3. In Sanity Studio, click "Add Item" in the image field
4. Upload the image
5. Add the proper alt text (copy from this guide)
6. Save the document

### Step 3: Image sizes to use:
- **Hero Images**: 1200x400 or 1920x1080
- **Profile Photos**: 400x400 or square format
- **Cover Images**: 1200x630 or 16:9 ratio
